# EduAssistAI

## SDG Selected
SDG 4 - Quality Education

## Project Description
EduAssistAI is an AI-powered educational assistant developed using Dialogflow and web technologies. The chatbot helps students by providing academic information, study resources, exam guidance, and career advice.

## Features
- Academic Query Assistance
- Study Resources Recommendation
- Exam Information
- Career Guidance
- AI Chatbot Support

## Technologies Used
- HTML
- CSS
- JavaScript
- Dialogflow
- GitHub Pages
